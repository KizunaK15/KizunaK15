Saya merancang arsitektur kontrol sistem tertanam, navigasi robotika otonom berbasis ROS 2, dan integrasi telemetri perangkat keras ke antarmuka perangkat lunak.

### Fokus Pengembangan Saat Ini
* **RAMABOT V3:** Pengembangan robot bergerak otonom medis menggunakan NVIDIA Jetson Xavier NX, ROS 2 Humble, SLAM Toolbox, serta sistem telemetri medis BLE GATT pada ESP32-C3 dan M5Stack.
* **Riset & Rekayasa:** Pemrosesan sinyal sensor real-time, kontrol aktuator presisi, dan sistem pemantauan industri berbasis IoT dan MQTT.

### Proyek & Rekayasa Pilihan
* **RAMABOT V3 Autonomous System:** Arsitektur navigasi SLAM dan pengambilan data telemetri medis nirkabel (BLE) secara langsung.
* **Revitalisasi Aktuator Linear ED-4270M:** Kontrol servo AC Mitsubishi MR-J2S-10A berbasis ESP32 dengan metode peredam getaran *Zero Vibration Derivative* (ZVD).
* **Industrial OEE Monitoring System:** Akuisisi data mesin produksi menggunakan ESP32, server lokal Orange Pi, broker Mosquitto MQTT, Node-RED, dan SQLite.
* **PRIME SmartHand Gloves:** Sarung tangan rehabilitasi pasca-stroke berbasis IoT untuk pemantauan gerak jari secara real-time.
